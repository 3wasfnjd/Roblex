# موديلات المرحلة الأولى للاستيراد في Studio

مجموعة مختارة من حزم Kenney (رخصة CC0) بصيغة GLB. لاستيرادها: Studio → تبويب Home → **Import 3D** → اختر كل ملفات مجلد واحد معًا (يمكن تحديد عشرات الملفات دفعة واحدة) → Import. كرّر لكل مجلد.

بعد الاستيراد: حدّد كل الموديلات المستوردة في Explorer → كليك يمين → **Save to File** باسم `imported-<اسم المجلد>.rbxmx` وارفعها إلى `island-race/import/` في المستودع.
