# سباق الجزر — Island Race

لعبة سباق وباركور على جزر طائرة، للفئة 10–14 سنة. وثيقة التصميم الكاملة في `docs/تصميم-اللعبة.md`.

## هيكل المجلد

| المسار | المحتوى |
|---|---|
| `docs/` | التصميم والقرارات |
| `src/ServerScriptService/` | سكربتات السيرفر (السباق، الاقتصاد، الحفظ) |
| `src/ReplicatedStorage/` | الموديولات المشتركة (الكتالوج، القواعد، الإعدادات) |
| `src/StarterPlayer/StarterPlayerScripts/` | سكربتات العميل (الواجهة، المركبات، المؤثرات) |
| `tools/` | أدوات البناء (تجميع المصادر في ملف المكان) |
| `build/` | ملف المكان الناتج `Island-Race.rbxlx.gz` للنشر |

الموديلات المشتركة (حزم Kenney وغيرها) في مجلد `models/` بجذر المستودع.

## الفرع

العمل على هذه اللعبة في فرع `island-race`. ماب «بوليفارد جود» يبقى في `main` ولا يتأثر.
